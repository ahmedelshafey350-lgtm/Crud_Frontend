# Course Hub (React + Vite)

1. `npm install`
2. `cp .env.example .env` وظبط `VITE_API_URL` على عنوان الباك اند
3. `npm run dev`

لو شكل الـ responses عندك مختلف (اسم حقل التوكن، شكل لستة الكورسات، أو create بياخد array) عدّل في `src/api.js` بس.
على الباك اند لازم تفعّل CORS للعنوان `http://localhost:5173`.
